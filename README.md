# Systems Engineering Framework Agent

Producto que integra:

- el marco de ingeniería de sistemas;
- el contrato runtime del agente;
- las skills ejecutables;
- el adaptador inicial para Codex;
- el instalador y actualizador para Windows.

## Alcance del MVP

El producto administra únicamente su superficie instalada:

- marco/;
- AGENTS.md;
- skills;
- adaptador Codex;
- manifiesto y hashes.

Nunca modifica los datos de proyecto.
