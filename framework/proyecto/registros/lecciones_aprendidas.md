# Registro de lecciones aprendidas

## Objetivo
Capturar aprendizajes útiles durante el proyecto y consolidarlos al cierre.

## Campos mínimos por entrada
- ID
- Fecha
- Fase
- Hallazgo
- Impacto observado
- Recomendación
- Estado de adopción

## Regla
No dejar las lecciones aprendidas solo para `F8`; capturarlas desde que aparezcan.
