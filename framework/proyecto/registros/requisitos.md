# Registro de requisitos

## Objetivo
Mantener una fuente trazable de necesidades, stakeholder requirements y system requirements.

## Campos mínimos por entrada
- ID único
- Tipo: necesidad / stakeholder requirement / system requirement
- Fuente
- Redacción
- Rationale
- Prioridad
- Asignación
- Método de verificación previsto
- Estado
- Trazabilidad hacia arriba y hacia abajo

## Uso en presupuesto
Permite cargar necesidades y requerimientos preliminares sin forzar aún la formalidad completa de `F2`.
