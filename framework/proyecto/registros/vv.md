# Registro de verificación y validación

## Objetivo
Mantener la estrategia de cierre de requisitos y su evidencia asociada.

## Campos mínimos por entrada
- ID de requisito
- Método de verificación
- Evidencia esperada
- Evidencia disponible
- Estado de verificación
- Criterio de validación relacionado
- Estado de validación

## Regla
No mezclar verificación con validación. Deben convivir en trazabilidad, pero con propósitos distintos.
