# Registro de configuración

## Objetivo
Identificar documentos, artefactos, versiones, baselines y cambios aprobados.

## Campos mínimos por entrada
- ID del ítem
- Nombre del ítem
- Tipo
- Versión
- Estado de aprobación
- Baseline asociada
- Ubicación
- Cambio relacionado
- Configuración ensayada o liberada, si aplica

## Regla especial
Las baselines del proyecto deben quedar registradas aquí aunque los tags o releases se gestionen luego en Git.
