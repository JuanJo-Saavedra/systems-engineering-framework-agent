# Registros transversales

Estos registros viven durante todo el ciclo de vida. En presupuesto pueden existir en nivel preliminar; al aprobarse el trabajo se consolidan y continúan.

## Regla general
- No crear registros paralelos para presupuesto y proyecto formal.
- Mantener continuidad histórica en el mismo archivo o estructura.
- Referenciar decisiones, artefactos y evidencias con identificadores claros.
