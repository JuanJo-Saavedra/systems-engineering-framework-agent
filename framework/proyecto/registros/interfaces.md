# Registro de interfaces

## Objetivo
Identificar, acordar y controlar interfaces internas y externas.

## Campos mínimos por entrada
- ID de interfaz
- Tipo: interna / externa
- Elementos involucrados
- Responsable
- Descripción
- Estado
- Documento ICD asociado
- Riesgos o decisiones relacionadas

## Uso en presupuesto
Puede existir una lista preliminar de interfaces externas relevantes, incluso si las internas todavía no están definidas.
