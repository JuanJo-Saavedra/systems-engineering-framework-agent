# Catálogo de baselines

## Functional Baseline
- Define qué debe hacer el sistema.
- Incluye requerimientos funcionales, desempeño, interfaces externas relevantes, restricciones principales y criterios preliminares de verificación.
- Se congela al cierre de `SRR`.

## Allocated Baseline
- Define cómo se distribuyen los requerimientos entre subsistemas o CIs.
- Incluye arquitectura funcional, física preliminar, asignación de requerimientos, interfaces preliminares y estrategia de integración y verificación.
- Se congela al cierre de `PDR`.

## Product Baseline
- Define cómo se construye, integra y ensaya el producto.
- Incluye diseño detallado, PBS final, ICDs finales, BOM, definición liberable de HW/FW/SW y procedimientos relevantes.
- Se congela al cierre de `CDR` o antes de implementación física, según el proyecto.

## Baseline final liberada
- Refleja la configuración transferida, producida o entregada.
- Incluye registros as-built / as-tested y el cierre técnico final.
