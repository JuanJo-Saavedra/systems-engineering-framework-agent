# Marco metodológico

Esta carpeta contiene la definición reusable del proceso de ingeniería. No describe el estado de un proyecto particular; define cómo debe operar cualquier proyecto que use esta plantilla.

## Contenido
- `fases/`: contratos operativos de `F0` a `F8`.
- `reviews/`: catálogo de reviews obligatorias y su intención.
- `baselines/`: catálogo de baselines y criterio de congelamiento.
- `reglas_del_ciclo.md`: reglas globales del flujo.
- `glosario.md`: términos y siglas usados por la plantilla.
